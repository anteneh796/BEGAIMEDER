# BEGAIMEDER ACADEMY

Premium digital school website and CMS platform for BEGAIMEDER ACADEMY (KG–Grade 8).

## Current foundation

- Next.js App Router
- React + TypeScript
- Responsive premium design system
- Public homepage foundation
- Initial CMS dashboard at /admin
- Prepared for Laravel API/CMS integration
- Media-first architecture

## Product direction

The platform will evolve into a complete school digital experience:

- Public website
- News and stories
- BEGAIMEDER Moments social-style publishing
- Photo/video media library
- Events and announcements
- Staff directory
- Academics
- Admissions
- Visual page builder
- SEO management
- Roles and permissions
- Publishing workflow
- Analytics
- Audit logging

## Development

```bash
npm install
npm run dev
```

Open http://localhost:3000 and http://localhost:3000/admin.

The public UI currently uses remote Unsplash imagery as temporary visual content. Production media will be served through the CMS media pipeline/CDN.
